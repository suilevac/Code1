# Découvrir le sept

Page interactive pour le TBI (grande section), sans texte :

1. ranger les cubes dans la boîte de 6 (chaque cube rangé reçoit son numéro), en laisser un à côté ;
2. entourer la boîte : les étiquettes du 6 apparaissent et se posent sur la boîte ;
3. entourer la boîte et le 7e cube : l'ardoise apparaît, le 7 se révèle au fil des points posés ;
4. trois élèves écrivent le 7, chacun avec sa craie ;
5. jeu final : ranger les écritures du 7 puis du 6 dans la bonne boîte.

Ouvrir `index.html` dans un navigateur.
