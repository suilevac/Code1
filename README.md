# Points alignés CE1

Ouvre `index.html` dans un navigateur (tablette conseillée). Aucun logiciel à installer.

- Objectifs : trouver des points alignés (par 3, 4, 5 ou 6), repérer le milieu, placer le milieu, placer un point aligné avec deux points.
- Outils de l'élève : crayon rose et crayon bleu, Entourer, Tracer, Surligner, Point, Retour.
- Règle numérique graduée en centimètres entiers : on la déplace au doigt, on la fait tourner avec le curseur ou la poignée ronde. Elle tourne autour de son 0.
- Réglages enseignant : bouton engrenage en haut à droite (étapes de progression, nombre de points, précision, stylet seulement).
