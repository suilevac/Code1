Mode d'emploi

Le code. Une couleur par son-voyelle ; les consonnes restent noires. Un son nasal est entouré d'un rond, dans la couleur de sa voyelle (an, en, on, in, ein, un). Un son avec yod est dans un triangle (ill, ian, ion, ien).

Les traits. Un trait simple sous une lettre : elle ne se dit pas. Un double trait : elle fait le son [s].

Corriger. Le découpage est automatique : il se trompe parfois sur les mots rares, sur -ent (verbe ou son [an] ?) et sur ill. Les endroits douteux sont soulignés en pointillé orange. Cliquez sur la lettre pour choisir le bon code ; la correction est enregistrée dans ce navigateur et réutilisée ensuite.

Imprimer. Le bouton Imprimer n'imprime que la feuille de droite. Copier met le texte en couleurs dans le presse-papier (collable dans un traitement de texte), Exporter enregistre une page web autonome.
